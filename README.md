> *NERV or SEELE — same music, different agenda.*

Dangify is an Evangelion-themed Spotify music player with a NERV/SEELE theme toggle.  
Switch sides mid-session. The playlist stays. The aesthetic doesn't.

---

## Stack

| | |
|---|---|
| **Framework** | React + Vite |
| **Animation** | GSAP |
| **Styling** | SCSS · CSS Variables |
| **API** | Spotify Web API |
| **Deployment** | Vercel |

---

## Run locally

```bash
git clone https://github.com/NguyennDangg/Dangify.git
cd Dangify
npm install
npm run dev
```
